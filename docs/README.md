# Библиотека Geometric_lib

## Описание
Библиотека geometric_lib содержит формулы для вычисления периметра и площади геометрических фигур (круга, квадрата, прямоугольника и треугольника).

## Описание функций

### Функции для круга (circle.py)

**_area(r)_** - считает площадь круга

- _Параметры:_ r (float) - радиус окружности
- _Что вернет:_ (float) площадь круга

**_perimeter(r)_** - считает периметр круга
- _Параметры:_ r (float) - радиус окружности
- _Что вернет:_ (float) периметр круга

_**Примеры вызова:**_
```python
from circle import area, perimeter

print(area(3.0))       # Вывод: 28.274333882308138
print(perimeter(3.0))  # Вывод: 18.84955592153876
```

### Функции для квадрата (square.py)

**_area(a)_** - считает площадь квадрата

- _Параметры:_ a (int) - сторона квадрата
- _Что вернет:_ (int) площадь квадрата

**_perimeter(a)_** - считает периметр квадрата
- _Параметры:_ a (int) - сторона квадрата
- _Что вернет:_ (int) периметр квадрата

_**Примеры вызова:**_
```python
from square import area, perimeter

print(area(2))       # Вывод: 4
print(perimeter(6))  # Вывод: 24
```

### Функции для прямоугольника (rectangle.py)

**_area(a, b)_** - считает площадь прямоугольника

- _Параметры:_ a (int) - длина прямоугольника; b (int or float) - ширина прямоугольника
- _Что вернет:_ (int) площадь прямоугольника

**_perimeter(a, b)_** - считает периметр прямоугольника
- _Параметры:_ a (int) - длина прямоугольника; b (int or float) - ширина прямоугольника
- _Что вернет:_ (int) периметр прямоугольника

_**Примеры вызова:**_
```python
from rectangle import area, perimeter

print(area(4, 5))       # Вывод: 20
print(perimeter(4, 5))  # Вывод: 18
```

### Функции для треугольника (triangle.py)

**_area(a, b, c)_** - считает площадь треугольника

- _Параметры:_ a (float) - первая сторона треугольника; b (int or float) - вторая сторона треугольника; c (int or float) - третья сторона треугольника
- _Что вернет:_ (float) площадь треугольника

**_perimeter(a, b, c)_** - считает периметр треугольника
- _Параметры:_ a (int) - первая сторона треугольника; b (int or float) - вторая сторона треугольника; c (int or float) - третья сторона треугольника
- _Что вернет:_ (int) периметр треугольника

_**Примеры вызова:**_
```python
from triangle import area, perimeter

print(area(3.0, 4.0, 5.0))       # Вывод: 6.0
print(perimeter(3, 4, 5))  # Вывод: 12
```
